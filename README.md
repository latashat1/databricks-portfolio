# Databricks Data Engineering Portfolio

End-to-end data engineering projects built on Databricks, demonstrating medallion
architecture, Autoloader, Structured Streaming, Lakeflow Declarative Pipelines,
Databricks Asset Bundles (CI/CD), Workflows/Jobs orchestration, and Genie/Lakeview
dashboards.

## Projects
- [01_healthcare_claims_util](./01_healthcare_claims_util) - Healthcare claims &
  utilization analytics: bronze/silver/gold pipeline, provider fraud-risk ML
  feature table, scheduled Job, Lakeflow Declarative Pipeline (alternate
  implementation), Lakeview dashboard, and Genie space.
